⚙️ Section 2 : Référence technique : Prompts, variables dynamiques et modificateurs
Ce document détaille le fonctionnement interne et la logique d'assemblage des prompts au sein du générateur Perchance text-to-image. Il explique comment les directives visuelles positives et négatives sont traitées, comment les variables dynamiques s'injectent en temps réel via la syntaxe entre crochets, et de quelle manière les listes de modificateurs interagissent avec l'interface pour affiner le rendu final de l'image.
📝 1. Prompt
​L'instruction textuelle qui indique à l'IA ce que l'image doit afficher. Sur Perchance, les prompts sont généralement construits de manière dynamique à l'aide d'expressions entre crochets plutôt qu'écrits manuellement. Dans ce générateur, le prompt est assemblé au moment de la génération en concaténant l'option sélectionnée de chaque menu déroulant :
Pour des raisons techniques, les délimiteurs ne sont pas inscritent. BRAKET​input.artStyle.promptBRAKET; BRAKETinput.lighting.promptBRAKET; BRAKETinput.persona.promptBRAKET; BRAKETinput.descriptionBRAKET; ​(Voir main.pjs:78). Chaque élément de liste possède une propriété enfant prompt qui contient le fragment de texte qu'il injecte.
Bracket delimiters
Délimitation : ils encadrent du code JavaScript (variables, listes, opérations).
Évaluation : le code interne est exécuté à la volée lors de la génération.
Substitution : le résultat remplace automatiquement les crochets dans le prompt final pour produire un texte dynamique.
input
un objet unique qui regroupe toutes les entrées utilisateur du générateur, chacune étant accessible par son nom.
​input.lighting
l'option actuellement sélectionnée dans le menu déroulant « lighting ». Sur Perchance, les listes sont des objets de données ; il s'agit donc d'une liste / d'un nœud, et non d'une simple variable.
​input.lighting.prompt
une propriété enfant de ce nœud. Chaque option du menu déroulant « lighting » comporte un enfant prompt contenant le texte qu'elle injecte :
lighting ← le menu déroulant (une liste d'options) Backlit ← une option (un nœud) prompt = Lighting: Light source behind the subject... Candlelight prompt = Lighting: Soft, warm light from candles...
Ainsi, input.lighting.prompt se lit : « le prompt de l'option actuellement sélectionnée dans le menu déroulant lighting ». Si l'utilisateur choisit Backlit, cette expression s'évalue en Lighting: Light source behind the subject... ; s'il choisit Candlelight, elle prend la valeur du texte associé aux bougies.

⛔ 2. Prompt négatif (negative / negativePrompt)
​Le texte qui indique à l'IA ce que l'image doit éviter (ex. : worst quality, jpeg artifacts, watermark). Le plugin text-to-image de Perchance l'accepte soit via 3 options.
L'option du style d'art
Selon le style d'art sélectionné, celiu-ci injecte du texte par défaut dans la negative prompt.
Le menu déroulant ❌ Anti-description selective
C'est un thème pouvant être sélectionné où celui-ce contient un groupe de mots qui s'ajoutent également à la negative prompt.
Extra negative prompt.
Champ réservé
Il y a un champ prévue pour la rédaction du texte de la negative prompt.
Dans ce générateur :
negativePrompt = BRAKETinput.artStyle.negativeBRAKET, BRAKETinput.extraNegativeBRAKET
​(Voir main.pjs:79). Cela constitue une liste de base que l'utilisateur peut enrichir via les champs de saisie Anti-Description.
​🎚️ 3. Modifiers (Modificateurs)
​De courtes expressions de qualification que l'on peut ajouter à un prompt pour ajuster le style ou le contenu. Sur le framework text-to-image de Perchance, un champ de saisie de texte peut déclarer une liste modifiers ; chaque élément de cette liste devient un menu déroulant (ex. : "Add character...", "Add action...") situé au-dessus de la zone textarea. Sélectionner une option insère automatiquement son texte dans la zone.
Dans ce générateur :
modifiers = BRAKETinput.artStyle?.modifiers || nullBRAKET ​(Voir main.pjs:104). Ainsi, le style artistique choisi apporte automatiquement son propre ensemble de menus déroulants de modificateurs. De plus : modifierUpdates = "event:description.input, event:artStyle.change" ​Cette ligne réaffiche les modificateurs à chaque modification de la description ou lors d'un changement de style.
4.​ ⚖️ Guidance Scale
Au-delà de votre texte, ce réglage technique influence drastiquement la génération de l'image.
Le niveau d'obéissance : le Guidance Scale (ou CFG Scale) : Contrôle à quel point l'IA doit obéir strictement à votre texte. Une valeur basse donne plus de liberté créative à l'IA. Une valeur par défaut (souvent 7) offre le meilleur équilibre. Une valeur trop haute force l'IA mais risque de "brûler" l'image avec des défauts visuels.
📖 Pour Aller Plus Loin :
Comprendre le paramètre "Guidance Scale"
🔬 Guidance Scale expliqué
C'est le bouton que tu vois sur ton écran. Il dicte à l'IA à quel point elle doit écouter ton texte.
Bas (ex: 3) : L'IA lit ton prompt, s'en inspire vaguement, et fait ce qu'elle veut. Très créatif, mais peu précis.
Moyen (ex: 7) : C'est le réglage par défaut (comme sur ton image). Le compromis parfait entre obéir à tes mots et garder une belle esthétique naturelle.
Haut (ex: 15+) : L'IA devient terrorisée et essaie de forcer absolument tous tes mots dans l'image. Le problème ? Ça crée souvent des images "brûlées", avec des couleurs saturées, des contrastes affreux et des défauts visuels (le fameux "risky" de ta capture d'écran)
5. Seed
L'ADN de l'image, le Seed (Graine) : Un numéro unique (ex: 429183) qui sert de point de départ au "bruit" visuel de l'IA. Utiliser le même Seed avec le même prompt générera exactement la même image. C'est l'outil parfait pour modifier un petit détail du prompt sans changer complètement la composition !
6. ⚙️ Les Menus Déroulants (Injection Automatique)
Pour vous simplifier la vie et garder votre zone de texte propre, le générateur intègre des menus déroulants comme ❓ Add realism?. Lorsque vous sélectionnez une option, le système injecte automatiquement les tokensToken : Unité de base lue par l'IA. Désigne un mot-clé précis utilisé pour déclencher un effet visuel. techniques parfaits à la toute fin de votre prompt, sans que vous n'ayez à les taper.
Par exemple, sélectionner Quality ajoutera invisiblement ceci à votre image :
Injection "Quality" : ultra-high definition texture, restored clarity, 8k crisp resolution, photorealistic micro-details
Sélectionner Hasselblad injectera une colorimétrie de studio professionnel :
Injection "Hasselblad" : Hasselblad Natural Colour Solution (HNCS), Medium Format Camera With End-to-End, True-to-Life Dynamic Range, 5-Axis, 10-Stop In-Body Image Stabilisation
